# Engineering ADRs

Implementation decisions only (framework, library, infrastructure shape — cite INF-001 decision IDs per its §8).

**Product/design decisions do NOT live here** — they belong in `docs/product/18-philosophy/decisions.md` (the product ADR log, human-decision-only). Each log cross-references the other; neither duplicates.

Format: `000N-short-title.md`, one decision per file, status header (proposed/accepted/superseded).

**Numbering:** engineering ADRs are 4-digit (`ADR-000N`); product ADRs in the decision log are 3-digit (`ADR-NNN`). They are different registers: `ADR-004` (product: region model) ≠ `ADR-0004` (engineering: product families).
