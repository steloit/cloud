## Goal

Every agent defined under `.claude/agents/` is automatically discoverable and
invokable **by name** in the execution harness. Repository-defined agents take
precedence over any globally installed plugins. An unresolved repository agent
**fails fast** — no silent fallback to an unrelated global plugin.

(Founder framing: "INF-00X — Agent Registration". Filed under EOPS as the
Engineering-OS tooling owner; this is a tooling improvement, not an
implementation blocker.)

## Why

During autonomous implementation the mandatory ADR-0008 review pipeline needs
the repo's `reviewer` and `qa` agents. In the current harness those files exist
but are **not registered as invokable subagent types**, so `subagent_type:
"reviewer"` errors — and the only "reviewer"-named type available was the
machine-level `kernel:reviewer` **plugin**, which is explicitly rejected for
this repo (`docs/plan/kernel-workflow-review.md`, ADR-0008). The silent
availability of the plugin (with no repo agent to shadow it) caused a real
workflow drift: an external reviewer was invoked before it was caught. The fix
is to make repo agents first-class and to make unknown-agent requests loud.

## Acceptance criteria

- [ ] `.claude/agents/*.md` (reviewer, qa, research, docs — and any future
  agent) are resolvable by their frontmatter `name` as `subagent_type` values
  in this harness.
- [ ] A repository-defined agent name **shadows** any identically- or
  similarly-purposed global plugin agent (repo precedence).
- [ ] Requesting an unregistered agent produces a **hard error** that lists the
  repository-defined agents and the available runtime agents, and states "No
  automatic fallback is permitted" — never a silent substitution.
- [ ] The ADR-0008 pipeline can invoke `reviewer` and `qa` by name (removing the
  documented general-purpose-with-verbatim-prompts workaround).

## Interim (already in place, not part of this task's fix)

Until this lands, reviews run per ADR-0008's "reviewer identity is fixed and
repo-native" clause by executing the verbatim `.claude/agents/reviewer.md` and
`qa.md` instructions through a generic **read-only** runner (`general-purpose`),
never Kernel. This task removes the need for that workaround.

## Out of scope

- Rewriting the reviewer/qa agent instructions (they are the source of truth).
- Any change to the review POLICY (independent architecture + QA, read-only,
  mandatory, no Kernel) — that is invariant and already codified in ADR-0008.
