## What this is

US-3.3a's final QA sweep ran **137 mutations, killed 122**. Two of the survivors
were closed on that branch (Observe's exact path, which covered a fixed-namespace
route AND a wrong apiVersion; and the teardown desired-flag arm). These are the
rest — each one measured GREEN against the full cell-agent suite.

None is reachable today through a path a customer drives, which is why this is
`medium` and not a blocker on that branch. All are in code US-3.3a rewrote or
sits next to.

| # | mutation that survives | why it matters |
|---|---|---|
| 1 | `instancesOf`: delete the override branch (always 1) | a customer-pinned 3-instance HA cluster silently renders as 1 — a capacity AND billing divergence. Pre-existing, in a file US-3.3a rewrote. |
| 2 | `main.go`: `n > 0` → `n >= 0` on `POLL_INTERVAL_SECONDS` | `=0` reaches `time.NewTicker(0)` → panic at boot → crash loop, from one character. The 10s default is also unpinned (the test always sets the env). |
| 3 | TLS `MinVersion` TLS12 → TLS10 | the task claims the transport pinned; `RootCAs`, `InsecureSkipVerify` and `http://` are, these are not. |
| 4 | `hc.Timeout` 30s → 1h | the ONLY bound on an apply — `agent.Tick` passes its context straight through with no deadline, so one wedged request stalls every service on the cell for as long as this says. |
| 5 | `Observe`: swallow the JSON decode error | a 200 with a non-JSON body reads as `""` → provisioning → retried with no signal. |
| 6 | `NewCNPGRenderer`: delete the nil-applier panic | a renderer built with no applier fails at the first converge with a nil dereference — a crash instead of the construction-time refusal the panic exists to give. |
| 7 | `ValidateNamespace`: `ns[:3] != "env"` (accepts `envil`) | the refusal set is tested; the prefix's exact shape is not. NOT `env` itself — the untouched `len(ns) < 5` guard still rejects that, and an earlier version of this row said otherwise, overstating what the mutation reaches. |

## Acceptance criteria

1. Each row above has a test that fails when that mutation is applied, measured
   on a GREEN-baseline harness.
2. Rows 3 and 4 are asserted on the constructed client, not on a comment.
3. Row 1 asserts the rendered Cluster's `instances`, not just `driver.Spec`.
4. The three property sweeps QA proposed are considered rather than one-off
   cases: `exactlyOneDocument` over arbitrary bytes, `ValidateNamespace` over
   arbitrary strings (accepted ⇒ exactly one extra path segment, no `..`, no
   newline), and `statusFromPhase` over arbitrary strings (output always in the
   ADR-024 vocabulary, and terminal ⇒ a legal edge from provisioning).
