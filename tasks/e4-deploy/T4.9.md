## Goal

Masking is policy-driven and provable: org/project masking policies (column rules: redact/hash/synthesize, PII-shape defaults), applied fail-closed at environment creation, verifiable by check.

## Summary

Elevates T4.6's static v0 to the F14 contract (docs/product/05-features/feature-specs.md §F14 — founder-approved 2026-07-18): policies versioned like all policies (F11); DDL-aware sync feeds for long-lived envs (pgstream-style, per ADR-0003 reference stack); masking never plan-gated; the canonical demo line depends on this being true — `masked · policy` must be literal.

## Acceptance criteria

- [ ] A masked environment provably contains zero unmasked values for policy-covered columns (automated check, not assertion)
- [ ] No production-shaped environment exists without a named policy applied
- [ ] Masking failure blocks environment creation loudly (fail closed, remediation shown)
- [ ] Policy changes are versioned + audited (F11 grammar)
