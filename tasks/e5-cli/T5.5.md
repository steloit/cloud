## Goal

Output layer (tables/marks/json/quiet) as a shared package

## Summary

The SDK inherits this package (generated-core + ergonomics, 20-clients/sdk.md).

## Acceptance criteria

- [x] six status marks (✓ ◌ ! ✕ ○ ·), spec §1.2 verbatim; with color ON the mark and
      word remain (color never the sole carrier); NO_COLOR strips escapes losslessly;
      unknown statuses degrade to the word, never panic.

## Outcome

- `apps/cli/internal/output`: Mark (six marks), Money/MoneyMonthly (integer cents, the
  one arithmetic — canon $58/$208/$1.62 pinned), Table (aligned, ANSI-aware widths, no
  borders/truncation), JSON + RawJSON (API shapes verbatim — RawJSON re-emits the bytes),
  Quiet (ids only), and Problem (the §4 three-line render mapping problem+json to exit
  codes 3/4/5/6/7 — denied_by for 403s, ALL reasons for 409s, retry-after for 429s).
- The TS SDK (T5.6) inherits the same conventions per sdk.md; this package is the Go
  reference implementation.
