## Goal

TS SDK v0 (generated core + ergonomics layer)

## Summary

Generated from openapi.yaml per 20-clients/sdk.md; published alongside console slice-3.

## Acceptance criteria

- [x] the alpha loop scriptable from Node with typed responses — vitest against a
      scripted fetch: estimate → create carries `estimate_id` on the wire with the
      context env; pagination is an async iterator over {data, next_cursor}; errors are
      typed (QuotaExceededError.requiredPlan, ConflictError.reasons, remediation always
      preserved); reveal-once (the secret exists in the returned object and nowhere on
      the client); events.stream() resumes from the last frame's cursor; fmtMoney pins
      canon ($58/$208/$1.62) and rejects non-integers.

## Outcome

- `packages/sdk` (@steloit/sdk): Hey API generated core (`src/generated`, regenerated by
  `make gen-ts` — never hand-edited) + the thin ergonomics layer per sdk.md §2/§3:
  context carried at construction or per call, estimate-before-provision as the method
  signature (`services.create({estimateId})`), typed problem+json errors, iterator
  pagination, SSE stream with cursor resume, integer-cents money helper.
- Deliberately absent (sdk.md §3): any AI auto-apply helper; any create shortcut that
  hides the price; float money APIs.
- CI: SDK typecheck + tests joined the validate job; the SDK regenerates in the same
  gen pipeline that guards drift.
- Deferred to follow-ups: idempotent-read auto-retry with Retry-After (noted in US-5.4),
  runtime binding helpers (§4 — need the injection mechanism, E4), parity report in CI.
