## Goal

The CNPG driver behind one provisioner interface (ADR-0003 / INF-001 A4): render
a service's desired state into the CNPG/K8s manifests for cluster create,
snapshot-branch, hibernate/wake, and PITR-to-new-branch. The interface is
product-agnostic so E9 products (Valkey) reuse it unchanged.

## Authority — encode measured truth, do not re-prove it

Founder decision (2026-07-23): implement against **ADR-0007's measured behavior
as the contract**; NO live cluster (that evidence exists from T1.0). The golden
manifests are the validated shapes in `infra/k8s/control-plane/cnpg-cluster.yaml`
and `infra/spike/manifests/spike-*.yaml`. `contexts/provisioning.md` §Drivers and
`docs/plan/e1-substrate-design.md` §2/§3 govern.

Measured contracts the driver must encode (ADR-0007):
- `archive_timeout: 300s` — the RPO bound, by construction (A1.3 / F4).
- Branch = `VolumeSnapshot` → CNPG `bootstrap.recovery.volumeSnapshots` (measured
  branch e2e 52.4s; data-identical).
- PITR = new cluster, `bootstrap.recovery.recoveryTarget.targetTime` derived from
  the last archived WAL, **never wall-clock** (F4).
- WAL → GCS via `barmanObjectStore` + `gkeEnvironment: true` (workload identity,
  zero static keys, D5/F5).
- Storage on `pd-cell` storageClass, `db-storage` pool affinity + storage taint
  toleration (T1.2), retention 30d.

## Scope — rendering + orchestration only, apply is the seam

This builds the RENDER half of the reconciler's converge (US-1.3 §2:
"render manifests from desired, server-side-apply"). The actual k8s apply/exec is
behind the seam (the cell-agent's Renderer, a later live-integration task) — no
cluster, ~$0.

**1 · The provisioner interface** (`services/cell-agent/internal/driver/`)
- `Driver` (every product): `Render(DesiredService) (Manifests, error)` — grammar
  (product + shape + intent) → the manifests to apply. This is the interface E9
  reuses **unchanged** (the AC).
- `BranchingDriver` (Postgres-specific extension, the D2 primitive):
  `SnapshotBranch(BranchSource) (Manifests, error)`,
  `PITRBranch(BranchSource, targetTime) (Manifests, error)`,
  `Hibernate(cluster) / Wake(cluster) (Patch, error)`.
- `Manifests` is an ordered list of rendered objects (kind + YAML/bytes);
  substrate names live here — this is the INTERNAL plane, the driver's job is to
  translate grammar → substrate (D8 forbids substrate in CUSTOMER surfaces, not
  in the driver's output).

**2 · The CNPG driver** (`.../driver/cnpg/`)
- `Render`: a CNPG `Cluster` from product=postgres + shape (size → storage), with
  the measured parameters (archive_timeout, pd-cell, pool affinity, barman WAL,
  retention). instances from shape/scaling.
- `SnapshotBranch`: a `VolumeSnapshot` of the source + a `Cluster` with
  `bootstrap.recovery.volumeSnapshots`.
- `PITRBranch`: a `Cluster` with `bootstrap.recovery.recoveryTarget.targetTime` +
  `externalClusters` source; reject a wall-clock target with no archived-WAL basis.
- `Hibernate`/`Wake`: the CNPG declarative-hibernation annotation patch.
- Names/namespaces from the service+cell (never duplicated — one derivation).

**3 · Second-product proof** (`.../driver/valkey/` or a stub)
- A minimal Valkey driver implementing `Driver.Render` (NOT `BranchingDriver`) to
  prove the interface is reused unchanged (the AC). It need not be
  feature-complete — it proves the abstraction holds with a non-branching product.

## Acceptance criteria

- [x] `Render` produces a CNPG Cluster matching the validated golden
  (`cnpg-cluster.yaml` shape): archive_timeout=300s, pd-cell, db-storage affinity,
  barman WAL→GCS with gkeEnvironment, retention 30d
  (`TestRenderClusterMatchesGolden`, golden byte-compared).
- [x] `SnapshotBranch` renders VolumeSnapshot + a bootstrap.recovery cluster;
  `PITRBranch` renders recoveryTarget.targetTime and **refuses a target with no
  archived-WAL basis** (`TestSnapshotBranchManifest`, `TestPITRBranchManifest`,
  `TestPITRRequiresArchivedWAL`).
- [x] `Hibernate`/`Wake` render the annotation patch (`TestHibernateWakePatch`).
- [x] **The `Driver` interface is reused by Valkey unchanged** — proven at
  compile time (interface assignments) and runtime (`TestValkeyDriverReusesInterfaceUnchanged`);
  Valkey is deliberately NOT a `BranchingDriver` (`TestValkeyIsNotABranchingDriver`).
- [x] Rendering is **deterministic** — 50× same-input byte-identical
  (`TestRenderIsDeterministic`; `text/template`, no map ordering in output).
- [x] Substrate names appear only in driver OUTPUT (the grammar→substrate
  translation), never required in the input Spec (`TestNoSubstrateNamesRequireACustomerSurface`).
- [x] `archive_timeout` is the measured 300s RPO bound, asserted
  (`TestArchiveTimeoutIsMeasuredRPO`).
