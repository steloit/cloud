## Summary

Decide by SDK-core reuse (20-clients/sdk.md generated-core pattern).

## Acceptance criteria

## Outcome

Resolved by **Architecture v1 (ADR-0001, docs/architecture.md §1/§17)**: the CLI is **Go**
(single static cross-platform binaries, instant startup, one backend language with api +
cell-agent, shared internal packages) — "this also resolves Sprint-0 item SP0-2." The SDK
core stays **TypeScript**, generated from openapi.yaml (§17 pipeline: Hey API client →
packages/contracts/ts + the 20-clients/sdk.md ergonomics layer), satisfying the SDK-core
reuse criterion. T5.1 starts from Go; T5.6 builds the TS SDK on the generated client.
