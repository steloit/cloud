## Goal

The design owner adds the n=1 (hidden-environment) frame variants and the reveal coachmark microcopy to the gallery/design spec, per the ratified implicit-environment UX spec (`docs/plan/implicit-environment-ux.md`, ADR-037).

## Summary

The 152 frames were drawn against canon (3 environments), so every frame renders env chrome; the frames stay authoritative for the *revealed* state. The n=1 state needs frame variants (design-owner additions, human-only): project overview / create / service pages / Deploy / Observe / Billing / Settings **without** env pill, env columns, scope chips, or `?env=` — per the §4 table of the UX spec. Plus the one-time reveal coachmark: *"This project now has two environments. You're viewing production — everything you've built lives here, unchanged."* (microcopy pass like S8).

## Acceptance criteria

- [ ] n=1 variants specced for each §4 page family (or a single stated chrome rule the frames reference)
- [ ] Reveal coachmark microcopy finalized + registered (voice.md pass)
- [ ] The reveal rule (envs ≥ 2 ∨ previews) recorded in the design spec §M3 alongside ADR-013/037
- [ ] E8 four-state checks extended: chrome hidden at n=1, revealed everywhere at once at n≥2
