## Goal

Stamp the pending ADR-022 amendment (decision log, human-only): pricing axes recast per ADR-039 §4c (natural meter per product, presented by outcome, generalized exact-sum invariant) and catalog-structure review refinement 1 (in-database capabilities — Jobs incl. scheduling, basic Search, Vector — included with the Database, consuming its already-priced capacity, never separately metered).

## Summary

Also resolves two audit findings in the same ruling: the canonical Pro price (**$19** in INF-001 §6 vs **$29** in F9/design spec) and the tier-name mismatch (INF-001 §6 says "Team", everywhere else "Business"). INF-001 §6 correction itself is a 00-sources human edit (couples with the S9 pass).

Ratified as **ADR-041** (2026-07-18, commit 4e5b05b): product-first presentation (intent-tag

Vector are included Database capabilities **within plan allowances** (included, not unlimited;

canonical. F9 and contexts/billing.md updated in the same pass; T11.1's pricing tables cite

model's first demonstration.
