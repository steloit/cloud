## Goal

Leave-org / account-delete with grace windows

## Summary

**AC:** last-owner rule holds; self-deletion never plan-gated; org delete honors the 90-day rule (202).

## Outcome

- S-process: yaml first — `DELETE /me` (deleteAccount) + `POST /orgs/{org}:leave`
  (leaveOrg) added; all clients regenerated. models.md's "account deletion = T7.6's
  flow" is now real.
- `users.deletion_scheduled_at` grace-window column (purge is a later job).
- leave ≠ admin removal: leaving one org leaves your account and other memberships
  untouched (no global sign-out — the multi-org concern from T2.7's G6 removal).
- account deletion is the last-owner rule at ACCOUNT scope: ownership is never orphaned;
  the fix is transfer-or-delete, named per org.
