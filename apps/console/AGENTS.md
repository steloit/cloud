# Console app — Agent Guide

React SPA rendering all 152 frames of the Steloit console. Complete against MSW "canon mode";
being wired to the real API slice-by-slice (epic E8). Root AGENTS.md rules apply; these add to them.

## Stack & conventions

- Vite + React 19 + TanStack Router (file-based routes in `src/app/routes/`; **`?env=` is always a
  query param, never a path segment**) + TanStack Query + thin Zustand store.
- Tailwind v4 over LATTICE tokens (`src/styles/tokens.css`; dark default, `.light` class swap).
  Components are named for their design-system class contract: `Pill` renders `.pill`. **Never invent
  a component** — the contract lives in `docs/product/01-design-system/`.
- API client generated by Hey API from the spec (`pnpm gen:api`) — never hand-write API types.
- MSW canon mode serves `docs/product/19-canon` fixtures verbatim; canon mode ships forever as the
  demo world (ADR-026). Keep it working when adding real-API paths.
- Biome for lint/format · Vitest (the 16-qa arithmetic invariants are tests — imported, never retyped).

## UI grammar (the audits enforce these; keep them green)

- Four-state truth on every query-backed surface: loading skeleton / empty-with-CTA / error-with-
  remediation / data. Error-as-empty is a defect.
- Gated actions render **visible-but-disabled with the reason** (B6), never hidden.
- h1 grammar "Area · Thing" · one active rail item + one active snav item · pills always carry text ·
  money via `fmtMoney` (mono) · Esc closes overlays non-destructively · violet is AI-only.
- Microcopy verbatim from frames — the words are spec.

## Commands

```sh
pnpm --filter console dev        # canon mode
pnpm --filter console test | typecheck | lint | build
pnpm --filter console gen:api    # regenerate client after any openapi.yaml change
```
